# milk-sewage-wgs

This project focuses on the analysis of whole-genome shotgun metagenomic data from dairy farm environments, including milk and associated wastewater samples.

The repository is organized into three main areas:

* `pipeline/` contains the Snakemake workflow used to process the sequencing data;
* `data/` contains the lightweight, version-controlled tables used for downstream analyses;
* `analysis/` contains the Quarto notebooks and R code used to compare assembly-based and reference-based results.
